# Static Site

The final product will be static HTML, CSS, JavaScript, and sanitized JSON.

```text
src/     final frontend source, created only after upstream pipeline proof
public/  public static inputs such as versioned prediction JSON
dist/    generated deployable bundle
```

The final visual design is intentionally TBD until the model, holdout, live-scoring schema, and static delivery path are proven.

A minimal technical viewer may be added earlier for validation, but it is not the final design.
