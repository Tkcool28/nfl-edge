# Task05G Units / Risk Profiles Freeze V1

## User-approved risk profile names

The five Task05G staking profiles are frozen as:

| Profile | Bankroll per 1u |
|---|---:|
| Cautious | 0.50% |
| Conservative | 0.75% |
| Normal | 1.00% |
| Aggressive | 1.25% |
| Ultra | 1.50% |

These labels control staking exposure only. They do not change the underlying selector, recommended wager, football-model confidence, Task05F evaluation, or expected predictive performance.

## Ultra caution

**Ultra is the highest staking exposure setting. It does not imply higher expected performance, better picks, greater model confidence, or any increase in predictive edge.**

This warning is part of the frozen product contract for the Ultra setting and should be preserved when the later UI/settings layer is implemented.

## Scope boundary

Risk-profile choice changes only the bankroll percentage represented by one recommended unit. It must never alter selector ranking, candidate eligibility, recommended units, or model/evaluator outputs.

2025 remains sealed while Task05G staking policy is finalized.
